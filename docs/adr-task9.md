# Чтение с реплик и консистентность

## 1. Распределение операций чтения

| Коллекция | Операция                                            | Реплика   | Допустимая задержка |
| --------- | --------------------------------------------------- | --------- | ------------------- |
| products  | Просмотр карточки товара (название, описание, цена) | Secondary | До 5 сек            |
| products  | Поиск по категориям и ценам                         | Secondary | До 5 сек            |
| products  | Проверка остатков перед покупкой                    | Primary   | 0 сек               |
| orders    | Просмотр истории заказов                            | Secondary | До 5 сек            |
| orders    | Проверка актуального статуса заказа                 | Primary   | 0 сек               |
| orders    | Проверка заказа сразу после создания                | Primary   | 0 сек               |
| carts     | Просмотр активной корзины                           | Primary   | 0 сек               |
| carts     | Чтение корзины перед изменением или слиянием        | Primary   | 0 сек               |
| carts     | Просмотр старой или брошенной корзины для аналитики | Secondary | До 10 сек           |

## 2. Обоснование

**Products:** карточки товаров и каталог могут читаться с Secondary, поскольку небольшая задержка обновления допустима. Остатки перед покупкой необходимо проверять на Primary, чтобы снизить риск продажи отсутствующего товара

**Orders:** история заказов может читаться с Secondary. Актуальный статус и только что созданный заказ читаются с Primary, чтобы пользователь не получал устаревшую информацию

**Carts:** активные корзины читаются с Primary, поскольку товары и количество часто изменяются. Устаревшие данные могут привести к потере изменений или неправильному слиянию корзин

## 3. Примеры MongoDB

Чтение каталога с Secondary:

```javascript
db.getMongo().setReadPref('secondary');
db.products.find({ category: 'electronics' });
```

Чтение актуального заказа с Primary:

```javascript
db.getMongo().setReadPref('primary');
db.orders.findOne({ _id: 'order-101' });
```
